Sistema de Classificação de Carcaças (v2)

Rede Neural Convolucional com Pré-classificação e Dashboard Web

~90% redução no tempo de análise

📋 Descrição Técnica

Sistema completo de classificação de carcaças bovinas utilizando Redes Neurais Convolucionais (CNNs). A solução implementa um pipeline sofisticado de pré-processamento com YOLO + PyTorch para detecção e descarte de objetos irrelevantes, seguido de TensorFlow/Keras para classificação em 4 categorias.

🔧 Pipeline Técnico:

  • Pré-classificação: ResNet (PyTorch) detecta e descarta objetos inválidos
  • Processamento de Imagem: OpenCV + PIL para recorte, normalização e tratamento de canais RGB
  • Detecção de Objetos: YOLO/Ultralytics para validação de relevância
  • Classificação: CNN (TensorFlow) classifica em 4 classes com probabilidade e dimensionamento (px → metros)
  • Persistência: Dados e imagens armazenados em PostgreSQL para auditoria

🌐 Interface Web (Angular):

  • Galeria de imagens classificadas com filtros avançados
  • Correção manual de classificações para retreinamento
  • Classificação em tempo real via upload ou captura de câmera
  • Dashboard com histórico e estatísticas de classificação

⚙️ Backend (FastAPI):

  • Rotas assíncronas com validadores Pydantic
  • Autenticação JWT e autorização baseada em roles
  • ORM SQLAlchemy para operações em banco de dados
  • Camadas bem definidas: Controllers, Services, Models, Repositories
  • Gerenciamento de dependências com UV

📊 Resultados & Impacto:

Redução de ~90% no tempo de análise manual de carcaças, aumentando significativamente a produtividade do frigorífico. O sistema identifica automaticamente a classe de carcaça (escassa, mediana, premium) e calcula dimensionamentos precisos, gerando relatórios em tempo real.

Stack Tecnológico

Plataforma E-commerce Full Stack

Sistema de Vendas e Compras para Varejo com IA integrada

~80% redução em tempo operacional

📋 Descrição Técnica

Plataforma e-commerce completa desenvolvida como único contribuidor, abrangendo desde o levantamento de requisitos até deploy em produção. Sistema bidirecional permitindo tanto clientes realizar compras quanto acesso administrativo para gerenciamento de vendas, produtos e usuários.

💳 Backend (FastAPI):

  • API RESTful assíncrona com validadores Pydantic e type hints
  • Autenticação: JWT com separação de roles (Admin/Cliente) e criptografia BCrypt
  • Pagamentos: Integração com Mercado Pago (cartão, PIX, boleto) via webhooks
  • Notificações: WebSocket para alerts em tempo real (estoque, vencimentos)
  • Task Queue: RabbitMQ para processamento assíncrono (envio de emails, relatórios)
  • Banco de Dados: PostgreSQL (Supabase) com ORM SQLAlchemy e migrações via Alembic
  • Documentação: Swagger/OpenAPI integrada, logs com Logging, formatação com Ruff
  • Gerenciamento: Dependências com UV, exceptions customizadas

🎨 Frontend (Next.js + TypeScript):

  • Interface moderna com Tailwind CSS para design responsivo
  • Gerenciamento de estado com React Hooks
  • Padrão de componentes reutilizáveis e services
  • UX otimizada para vendedor e cliente com filtros avançados

🤖 IA & Automação:

  • RAG Agents: LangChain com LLMs (Google Generative AI, OpenAI) para atendimento inteligente ao cliente
  • Chatbot Conversacional: Agent de IA integrado na plataforma web com contexto de pedidos e produtos
  • Code Assistance: Copilot + GitHub Codex para aceleração do desenvolvimento

🚀 DevOps & Deployment:

  • Containerização: Docker + Docker Compose
  • CI/CD: GitHub Actions (testes automáticos, build e deploy em VPS Oracle)
  • Testes: PyTest (unitários, integração, automatizados) — pré-push validation

👥 Funcionalidades por Role:

Cliente:
  • Catálogo com filtros (nome, categoria, data)
  • Carrinho de compras
  • Checkout e pagamento integrado
  • Solicitação de retirada
  • Histórico de pedidos
  • Gerenciamento de conta
Admin:
  • CRUD de vendas, produtos, usuários
  • Dashboard com analytics
  • Histórico e filtros de vendas (pagas/não pagas)
  • Controle de estoque e vencimentos
  • Relatórios detalhados

📊 Resultados & Impacto:

Redução de ~80% do tempo operacional tanto em vendas quanto em compras, otimizando fluxo de trabalho para vendedores e melhorando experiência de compra para clientes. Sistema reduz erros manuais e integra pagamentos de forma segura e transparente.

Arquitetura de Microsserviços para Pagamentos

Integração de APIs de Pagamento via Message Queue

Em Desenvolvimento

📋 Descrição Técnica

Arquitetura de microsserviços robusta desenvolvida em Java com Spring Boot, focada em integração descentralizada de APIs de pagamento através de message queuing. O projeto implementa um padrão de Event-Driven Architecture permitindo comunicação assíncrona entre múltiplos serviços, garantindo escalabilidade, resiliência e desacoplamento.

🏗️ Arquitetura de Microsserviços:

  • Publisher Service: Publica eventos de checkout na fila, validando requisições iniciais
  • Consumer Service(s): Consome eventos e executa operações de pagamento em paralelo
  • Event-Driven Pattern: Desacoplamento de serviços via mensageria assíncrona
  • Retentability: Garantia de entrega de mensagens com retry policies e dead letter queue
  • Idempotência: Processamento seguro de mensagens duplicadas

🔐 Segurança & Autenticação:

  • Spring Security: Autenticação e autorização em rotas HTTP
  • JWT: Token-based authentication para chamadas entre serviços
  • Criptografia: Dados sensíveis criptografados em trânsito e em repouso
  • Validação: Validação robusta de payloads com Bean Validation

💳 Fluxo de Pagamento:

  • Checkout: Cliente inicia compra → Publisher valida e publica evento
  • Validação: Consumer valida credenciais e método de pagamento
  • Processamento: Chamadas a APIs de gateway de pagamento (Stripe, Mercado Pago, etc.)
  • Confirmação: Eventos de sucesso/falha publicados para atualizar estado
  • Auditoria: Logs detalhados de todas as transações para compliance

⚙️ Stack Backend (Java/Spring):

  • Spring Boot: Framework principal para microsserviços
  • Spring Data JPA: ORM para persistência de dados
  • Spring Cloud: Service discovery, config server, load balancing
  • RabbitMQ: Message broker para comunicação assíncrona entre serviços
  • Spring AMQP: Abstração para trabalhar com RabbitMQ
  • Spring Security: Framework completo de segurança
  • Bean Validation: Validação de dados com anotações

📊 Padrões de Design Implementados:

  • Event Sourcing: Histórico completo de eventos para auditoria
  • SAGA Pattern: Coordenação de transações distribuídas
  • Circuit Breaker: Resilência e falha graciosa em chamadas externas
  • Retry Pattern: Tentativas automáticas em caso de falha
  • Repository Pattern: Abstração de acesso a dados

📈 Benefícios da Arquitetura:

Escalabilidade Horizontal: Cada serviço pode escalar independentemente. Resiliência: Falha em um serviço não derruba o sistema inteiro. Desacoplamento: Serviços podem ser desenvolvidos e deployados independentemente. Assincronia: Processamento de pagamentos não bloqueia requisição do cliente. Auditoria: Rastreamento completo de todas as operações de pagamento.
